
# 🎧 Site de Música Interativo

Projeto de uma landing page musical interativa, desenvolvido com **HTML5, CSS3 e JavaScript** como parte de uma atividade prática do curso PROA.

O projeto tem como objetivo explorar a criação de interfaces visuais para sites de música, trabalhando com imagens de fundo, organização de elementos, estilização de páginas e integração de recursos multimídia com JavaScript.

## Funcionalidades e características

- Landing page com temática musical.
- Interface visual com imagem de fundo ocupando toda a tela.
- Menu de navegação horizontal.
- Título em destaque com tipografia personalizada.
- Botão interativo para reprodução e pausa de áudio.
- Alteração automática do ícone entre Play e Pause.
- Reprodução de arquivo MP3 utilizando o elemento HTML `<audio>`.
- Organização visual dos elementos com CSS.
- Interatividade desenvolvida com JavaScript.

## Tecnologias utilizadas

- **HTML5:** estruturação da página, menu de navegação e integração do elemento de áudio.
- **CSS3:** estilização, posicionamento, tipografia e configuração da imagem de fundo.
- **JavaScript:** controle da reprodução musical e alteração dinâmica do ícone.
- **Google Fonts:** utilização da fonte Poppins.

## Aprendizados

Durante o desenvolvimento, foram praticados conceitos como:

- Estruturação de uma landing page utilizando HTML.
- Criação e estilização de menus de navegação.
- Aplicação de imagens de fundo com `background-image`.
- Utilização de `background-size: cover` e `background-position`.
- Organização de elementos utilizando propriedades de posicionamento CSS.
- Integração de arquivos de áudio com a tag `<audio>`.
- Manipulação do DOM com `document.getElementById()`.
- Utilização de eventos `onclick` para controlar interações.
- Controle de reprodução com os métodos `play()` e `pause()`.
- Verificação do estado do áudio com a propriedade `paused`.
- Alteração dinâmica de imagens por meio da propriedade `src`.
- Aplicação de estruturas condicionais `if` e `else` em JavaScript.
